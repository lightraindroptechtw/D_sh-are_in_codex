# CC 改動核對與 Codex 0.9.4 驗證

日期：2026-10-28。先前 493 項測試通過，不能證明已移植 CC 全部功能。本次重新沿著入口、執行環境、審查、補寫和市場後端核對；兩份原始核對表在 ../v0.9.3/audit-runtime.md 與 audit-review-market.md，代表修改前的狀態。

| 項目 | 修改與驗證 |
| --- | --- |

## 驗證的範圍

完整測試：501 通過、0 失敗、0 跳過，開啟既有 Codex 整合及原生權限測試。紀錄：full-tests.log。實際版本對應摘要：native-capabilities.json。測試中有真實子程序、MCP（模型工具連接協定）呼叫和檔案操作；也有合成邊界及替代原生安裝／系統限制探測的測試，不能把它們算成 501 個社群插件。

多入口驗證包含：檢查來源 → 產生插件 → 預先編譯全部入口 → 啟動官方 DSH 執行環境 → 呼叫兩個原工具及兩個命令。來源是合成測例，不能推論 AgentMail 等真實插件的帳號功能已成功。

本次沒有模型試打、第三方發文、付費服務、帳號登入或額度重置。子代理先前的額度錯誤不能用來宣稱主帳號額度耗盡。

## 尚未與 CC 完全相同

| 項目 | 目前界線 |
| --- | --- |
| 原生 DSH 畫面 | 不能直接掛入 Codex 聊天元件。可補寫獨立網頁；尚無通用 DSH 前端相容環境。 |
| 完整 DSH 代理／命令生命週期 | 全域命令可執行，不代表所有 agent.session、agent.send 等原生操作都已對應。 |
| 純畫面插件的正式分類 | 分類函式存在，但正式轉換入口仍未完全採 CC 的不適用分類；不能把產出宿主程序稱為畫面可用。 |
| 目前對話的工具清單 | 審查可讀版本對應的協定摘要，並由主對話核對其實際工具。尚無可供任意補寫程式直接使用、等同 CC $ 的統一物件。方法存在不等於有權限。 |
| 補寫結果細分 | 已附新增能力、實作及限制；尚未有 CC 同等的逐原始功能完成狀態與結構化審查意見回存。hooks/rewrite 仍只是資源，不會自動掛上原生事件；新增任意外部依賴亦未有完整自動準備流程。 |
| 下載刪除 | 會刪除未安裝的來源與下載紀錄；相關審查報告、補寫草稿尚未一併清除。本機資料夾審查也未完全共用下載清單。 |
| 多語後端通知 | 市場介面沿用 CC 多語版；部分後端回覆仍為繁體中文，尚未統一使用 CC 的訊息代碼及參數。 |
| 設定立即生效 | 部分程序權限改動在下一次工具呼叫重建執行環境，不等於所有背景工作立即切換。沒有為了相同表面效果自動重試可能已產生副作用的失敗工具。 |
