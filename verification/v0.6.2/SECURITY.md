# 0.6.2 安全與權限分離

日期：2026-10-24。以使用者最後確認的兩項為主：避免金鑰洩漏、分開檔案修改權限。使用 Codex 原生限制；正常本機連線不另行禁止。介面風格修改保持暫停。

## 已修正

1. 來源出現 process.env.NAME 不再被當成讀取授權。來源要求只列名稱，市場生成程序不繼承憑證環境。
2. 指定 Codex 登入／設定、常見憑證路徑、市場審查簽章金鑰與存取授權紀錄禁止讀取。未知位置的任意金鑰不會自動被辨識；這不是保證找出整台電腦所有秘密。
3. Node 經 Codex 原生 Windows 沙箱啟動；程式與一般檔案唯讀，只能直接修改專用狀態資料夾，衍生子程序亦受限制。每次啟動以前用合成資料核對限制。
4. 本機連線保留，不宣稱完全封網。原先要求全面拒絕連線的條件已依使用者指示取消。
5. 超出權限的操作交回聊天中的 Codex，用其原生工具、既有權限與核准流程處理。這不是來源自動提權服務；原插件若需在同一函式中取得結果才能繼續，仍需適配。
6. 安裝前 Codex 審查固定來源；正常能力與中度提醒可以通過，不再把依賴版本範圍或一般檔案、網路功能當成惡意證據。具體高危、未判讀程式或竊取金鑰仍阻擋。
7. 審查綁完整檔案清單及雜湊，來源、依賴或產物變動須重新準備；磁碟上自填批准或重算公開雜湊不能替代目前程序持有的批准。
8. npm 停用安裝腳本；實際第三方依賴另審查。固定 GitHub 提交使用有限量壓縮包，不執行來源 Git 簽出。下載核對實際公開 DNS（網域名稱解析）位址並限制重新導向、大小與時間。
9. 市場全部 API（程式介面）要求每次啟動的隨機授權；寫入再驗同來源與防偽造請求。這不防同一 Windows 帳號的惡意程式改寫整個轉換器或讀取自己的市場設定。
10. 公開直接轉換、來源驗證呼叫、Python setup、背景啟動與遠端 inspect 已封鎖，避免繞過安全準備流程；本機唯讀分析、結構檢查、背景狀態／停止與市場仍可用。

## 證據與邊界

此版未重跑 100 個第三方來源。AI 審查不是安全證明；固定宿主套件屬轉換器既有信任基礎，本次沒有逐行重審其全部原始碼。舊版生成包不會自動取得新限制，當前聊天已載入的舊工具需要新開聊天載入新版。

可編輯指引：data/security-review-prompt.md、data/permission-handoff-skill.md。使用者不必為正常插件操作逐次人工核准；需要核准的動作由 Codex 當下原生工具政策決定，插件本身不能自行批准。


來源 Node 另啟用 Permission Model（權限模型），限制檔案讀寫與自行啟動子程序。它是已審查程式的額外防呆，不是對惡意程式的強安全邊界；作業系統層仍負責限制檔案修改。Windows 原生禁讀實測曾出現不一致，因此不把僅設定 deny 當成金鑰讀取已被阻擋的證明。超權限操作由 Codex 原生工具評估處理，不是插件自動獲得提權。
另以 Node 權限模型驗證外部合成憑證、外部寫入、子程序皆拒絕；自己的資料夾可寫。預編譯的所有載入檔案包含 JSON 均核對真實路徑，禁止在準備階段打包插件目錄以外的檔案。
