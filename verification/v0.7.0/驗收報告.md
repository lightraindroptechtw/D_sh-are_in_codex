## 十節標準對照

|標準|實作與證據／平台差異|
|---|---|
|一、風險說明|README、相容性及功能限制文件均明載第三方程式風險、AI 非保證、完整存取權建議；不當安裝門檻。|
|二、模型與子代理|預設開啟、每插件開關、逐次本機通知；使用既有 Codex 登入及額度。真實模型回合本輪未執行；已驗證控制介面與合成回合、工具回呼。|
|三、指令|不經模型的本機規則檢查與核准，結果回原函式；完整存取權不詢問。無法完全重用 Codex 聊天原生核准畫面、未公開規則；以本機確認頁替代。不能宣稱完全一致。|
|四、Node 讀寫與開程式|允許工作資料夾讀寫、額外資料夾、直接啟動開關、整體關閉選項；不額外限制網路。官方環境原生模組載入、翻譯記憶等寫入、原生子程序依賴解析有回歸測試。|
|五、發文|每次確認／自動／禁止；確切三個按鈕、持久設定、一次提醒、通知、紀錄及自動模式限量。跨程序預留次數避免並發超量；合成測試沒有真實送出。|
|六、工具攔截|預設關閉；開啟後只能阻擋，不能改寫原生工具參數。一般事件與來源計時器沒有一起關閉。|
|七、金鑰|插件外本人專屬檔案權限；沒有已驗證的 Codex 安全儲存區介面。只有已宣告且填寫的值，精準遮蔽至少六字元的已知值；指令不繼承金鑰環境。空白金鑰欄位也會建立敏感欄位供補填。|
|八、審查|下載後先固定掃描，原樣列出檔案／行號／內容與資產；AI 只複查標記位置。AI 未完成或高風險可由使用者繼續；不可讀混淆可明確強制。附安全報告與白話說明。|
|九、完整性及放寬|保留既有完整性、解壓、來源網址、停用安裝腳本。重啟可恢復已準備項目、核對後安裝；部分元件可保留；直接與本機轉換恢復。|
|十、受限通知|工具結果、本機設定通知、報告、目前受限功能，均列什麼／原因／設定／影響。啟動失敗仍保留狀態、設定及重試工具；不把這些輔助工具當來源功能成功。|

## 無法宣稱已完成的能力

- Codex 權限附帶資料不含當前模型、思考強度、完整核准設定與所有禁令；下一次工具呼叫才得知權限變更，不能立即同步純畫面切換後的背景工作。
- 本機通知與確認頁已接通；沒有原生桌面通知服務，亦不是 Codex 原生核准視窗。
- Node 的資料夾限制不是惡意程式的完整隔離，也不會自動套到 Python、原生外部 MCP 或使用者允許直接開啟的程式。
- 發文以辨識出的工具與手動清單管制；不能保證攔截第三方程式任意 HTTP 或外部程序繞過。
- 影片插件目前有狀態工具與 Python／代理工具連接的合成驗證，尚未完成登入後看影片、留言、定時值班的完整實測。依本次要求沒有真正發文。
