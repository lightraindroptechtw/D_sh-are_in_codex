# 0.5.0：可直接操作的 DSH 社群插件市場

交付日期：2026-10-24（台北）。現用轉換器已透過真正 Codex 的插件安裝命令更新至 0.5.0，桌面新增「DSH 插件市場」捷徑。

## 人類操作

雙擊桌面捷徑 → 搜尋或選分類 →「了解插件」→「準備安裝」→ 閱讀保留／略過內容 →「確認安裝到這台電腦」→ 新開 Codex 聊天。

頁面內附在插件中，透過本機瀏覽器顯示；不修改 Codex 原生插件頁，也不需要 AI 操作。轉換及確認安裝不初始化來源；新聊天載入生成插件時才可能執行其程式。只開頁、搜尋或閱讀介紹，不會安裝任何來源插件。

桌面捷徑：`<local-workspace> 插件市場.lnk`。

現用程式：`<local-workspace>`。

市場資料：`<local-workspace>`。生成的插件透過本機市集交由 Codex 安裝，快取位於 `~/.codex/plugins/cache/dsh-community-converted/`；使用同一個 Codex 插件載入機制。

## 範圍與限制

- 市場顯示的用途是社群作者資料；不能把列入清單、產物結構合法或列工具成功，當成全部功能已驗證。
- 純 DSH 聊天介面及內部模型流程無法直接搬進 Codex；混合插件只保留可轉換內容。
- 功能標記比對明確插件版本並顯示當時的轉換器版本；0.4.1 舊紀錄沒有冒充 0.5.0 全量重測。財務私有修正副本的成績不套用至市場原包。
- 本版已安裝列表記錄經本市場完成的安裝；不是其他 Codex 市集插件的總清單，也不追蹤使用者在別處手動移除或更新的結果。本版未提供移除及更新按鈕。
- npm 下載有大小、完整性與解壓限制，安裝依賴停用腳本。Git 固定完整提交，有逾時限制，尚無傳輸位元組硬上限；本版沒有經完整頁面安裝 Git 來源。
- 掛鉤及背景模型流程在市場轉換中停用；不能把本次工具安裝測試當成掛鉤或完整 DSH 代理流程測試。
- 需要 Node.js 22.19.0 以上、npm、可使用的 Codex 命令；Git 來源另需 Git。程序隔離不等於作業系統安全沙箱。

先前 100 來源及擴大功能抽測維持原日期、版本與限制，見 [0.4.1 交付報告](../v0.4.1/RELEASE-RESULTS.md)。
