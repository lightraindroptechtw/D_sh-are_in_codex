## 三個正式入口

| 技能選單名稱 | 原生完整指令 | 功能 |
|---|---|---|
| 開啟 DSH 插件市場 | `$dsh-to-codex:dsh-market` | 在 Codex 右側開市場 |
| 審查 DSH 插件 | `$dsh-to-codex:scan` | 直接提供來源，審查而不安裝 |
| 審查並安裝 DSH 插件 | `$dsh-to-codex:install` | 審查後取得同意，轉換並安裝同一固定來源 |

兩個來源入口接受 npm 名稱、npm:名稱@版本、公開 GitHub 網址或本機資料夾，不必先逛市場。主對話審查，不另外開模型或子代理。完整原文報告保存在本機，模型只取得代表片段。

```text
$dsh-to-codex:scan npm:插件名稱@版本
```

```text
$dsh-to-codex:install npm:插件名稱@版本
```

升版後背景市場若仍是同一插件的舊版，沒有工作執行時會自行更新服務；保留已審來源與設定資料，不要求使用者手動關服務。

## 使用方式

1. 安裝插件後，在 Codex 輸入 `$` 選「開啟 DSH 插件市場」，或直接說「開啟 DSH 插件市場」。插件會啟動服務並在目前對話右側開啟，不需捷徑、固定網址或手動啟動。完整技能指令為下列可複製內容：

```text
$dsh-to-codex:dsh-market
```

2. 一般搜尋不使用模型；「Luna 搜尋」用現有 ChatGPT Codex 登入，先產生關鍵字，再從最多40個精簡候選挑選。搜尋不是安全審查。
3. 按「審查並安裝」只下載固定來源並掃描，不執行插件、不另開模型審查。
4. 主對話使用 get_dsh_market_reviews 領取代表片段；讀完後白話回報，再用 complete_dsh_market_review 把意見寫回市場。模型與思考強度沿用主對話本身。
5. 回市場查看報告、勾選同意後轉換，再查看保留功能與權限並安裝。也可只看固定掃描繼續；AI 意見不是安裝門檻。
6. 安裝後新開 Codex 聊天載入。工具列可切換已安裝與收藏；已轉換待安裝項目會顯示在已安裝管理清單。

從目前 Codex 對話開啟市場後，按下審查會透過桌面內建通道送出一句簡短要求；操作步驟與待審識別碼由技能和工具取得，不整段顯示在聊天裡。這是目前桌面版本的內建介面，不是公開穩定契約；無法連線時會明確顯示尚未送達，可從目標對話重新開啟市場或手動要求讀取待審項目，不另開模型補做。桌面捷徑只是開發者本機的選用入口，發行插件不依賴它。

~~~powershell
node ./bin/dsh-to-codex.mjs market --open
~~~

需要 Node.js 22.19.0 以上、npm 與 Codex 命令。瀏覽、掃描、轉換、安裝不要求模型登入；只有 Luna 搜尋和插件模型／代理需要現有 ChatGPT Codex 登入，不自行使用另外收費的 API，也不購買或重置額度。

- 普通壓縮碼不算混淆；JS／TS 的混淆指標不再誤套 Python 色盤及測試資料。

- 開啟直接執行程式時，一併允許工作執行緒、原生擴充與 WASI（WebAssembly 系統介面）。

- 插件安全設定新增「讓插件知道目前對話裡發生的事」（`shareConversation`，預設開啟）及「允許插件主動送出訊息」（`allowFollowups`，預設關閉）。舊設定缺少欄位時套用這兩個預設，勾選後儲存會保留選擇；不改模型與代理原有預設。已接上 Codex 主對話掛鉤，並測試事件轉送、紀錄查詢、目前模型與跟進訊息；不是只增加開關。


## 0.8.1 主對話功能

| DSH 功能 | Codex 版行為 |
| --- | --- |
| `session/event` | 將使用者訊息、工具呼叫與結果、最後回答、回合開始與結束轉成 DSH 格式。`shareConversation` 預設開啟，首次分享通知；只處理綁定的目前對話。 |
| `agent.followup` / `agent.send` | 主對話以一個代理提供給插件。`allowFollowups` 預設關閉；開啟後訊息先排隊，在回合結束時透過 Codex 繼續同一對話，或隨下一次使用者訊息交入。 |
| `sessionQuery` | 只讀插件接入後收到的目前對話事件，最多 2,000 筆；關閉分享後不能讀。不回讀更早歷史。 |
| `agentDefaultModel.currentSelection()` | 唯讀取得主對話掛鉤回報的實際模型；尚未回報時 model 是 null，不以預設模型冒充。 |

這裡描述的是第三方插件的掛鉤跟進方式，並非市場的桌面提交通道。第三方插件仍未直接接上閒置桌面喚醒，因此排隊不等於立即開新回合；畫面會通知這個差異。自動延續的回合不會再自動延續，後續訊息留待下一次使用者送出訊息。這不另開 `codex exec` 或子代理冒充主對話。需要信任並啟用生成插件的掛鉤（hooks）；安裝本身不代表掛鉤已受信任。

本次更新的是轉換器與新生成的插件。既有已轉換插件含獨立的程式副本，需重新轉換並安裝才能取得這四項連接；使用者的安全設定會沿用。驗證範圍與結果見 `verification/v0.8.1/驗收報告.md`。

## 權限與風險

這些插件執行第三方程式碼，風險高於單純使用 Codex。所有保護只能降低風險，AI 審查不是安全保證。會發文或開子代理的插件，不建議在完整存取權模式下使用；這些提醒不作為拒絕插件的理由。

來源可讀插件／狀態／工作資料夾，可寫狀態／工作資料夾；可自行增加資料夾或關閉額外限制。網路不額外限制。直接開程式預設關閉，有對應開關。模型和子代理預設開啟並通知；攔截 Codex 工具預設關閉，開啟後只允許阻擋。

金鑰填在插件外的敏感欄位，只傳已宣告且使用者提供的值。已知至少六字元的值會在結果、通知、確認與日誌遮蔽。發文支援每次確認／自動／禁止，保留通知、紀錄及使用者設定的數量限制。

保留既有雜湊、安全解壓縮、來源下載私人網路限制及停用依賴安裝腳本。混淆程式可用明確強制選項繼續。圖片、字型、AI逾時或可疑結論，不會使正常插件整包不能安裝。
